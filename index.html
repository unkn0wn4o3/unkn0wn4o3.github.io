A FEW DETAILS

Frequently asked.

Why have a personal website? +

It gives you one place to introduce yourself, showcase projects, collect links, and document what you're learning.

Will this website cost money? +

The static website and GitHub Pages hosting can be free. A custom domain is optional and usually costs money. You can use the free github.io address instead.

Can I update it later? +

Yes. Edit the files in your GitHub repository and commit the changes. GitHub Pages republishes the site after the update.

Do I need to know coding? +

Not to publish this starter. You can edit the text and links in the files. Learning basic HTML and CSS will help you customize it further.
