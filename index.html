07 / QUICK ANSWERS

A few details.

The practical bits, without the mystery.

Is this website free? +

Yes. The site is static and hosted with GitHub Pages, so you can keep using the free github.io address. A custom domain is optional and usually costs money.

How do I update the content? +

Open the repository, edit a file such as index.html, and commit the change. GitHub Pages republishes the site after the update.

Does the contact button send messages? +

This starter does not use a backend or store messages. Add a public email link only if you’re comfortable sharing that address.

Can I change the look later? +

Yes. Most visual settings live in styles.css. Keep a copy of the working files before making major edits.
