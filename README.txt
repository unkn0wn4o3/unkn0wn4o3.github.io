UNKNOWN403 — WEBSITE ZIP

CONTENTS
- index.html: all website sections and content
- styles.css: layout, colours, responsive design, and animations
- script.js: mobile navigation, scroll progress, and reveal effects
- assets/: your uploaded images, organised by category

PUBLISH WITH GITHUB PAGES
1. Extract this ZIP on your computer.
2. Open your GitHub repository: https://github.com/unkn0wn4o3/unkn0wn4o3.github.io
3. Upload the contents inside the extracted folder (not the outer folder itself) to the repository root.
4. If GitHub asks whether to replace existing files, review the changes and confirm.
5. Commit the changes. GitHub Pages should publish the site automatically.

NOTES
- Images are bundled locally in assets/; no remote image host is required for the supplied artwork.
- Google Fonts are loaded externally when internet is available; the site falls back to system fonts.
- Game/show/movie descriptions are humorous website copy, not ratings or claims about play history.
- Some franchise categories use one supplied franchise poster while listing the films in the accompanying text.
