# Personal Brand Website — Starter Kit

A responsive, dark minimalist personal website built with plain HTML, CSS, and JavaScript. No frameworks, paid fonts, external image dependencies, or build tools are required.

## Files

- `index.html` — all website content and sections
- `styles.css` — colours, layout, responsive styles, and animations
- `script.js` — mobile navigation and automatic footer year
- `favicon.svg` — simple browser-tab icon

## Before publishing: personalize these items

Open `index.html` and use Find/Replace to update:

1. `YOUR_ALIAS` → your online alias.
2. `YOUR_EMAIL@example.com` → an email address you are comfortable sharing, or remove the email button.
3. The meta description in the `<head>`.
4. The About, Interests, Right Now, Work, Journal, Goals, and FAQ content so it reflects you accurately.
5. Each social card's `href` → your own profile URL. Remove any networks you do not use. The starter links currently point to platform homepages, not your personal profiles.
6. Project and journal cards → real work and writing. Starter examples are placeholders, not claims of completed work.

You can also change `YOUR_ALIAS.space` to any short label you like; `.space` here is just text, not a registered domain.

## Preview on your computer

1. Extract the ZIP.
2. Open `index.html` in a browser.
3. Edit the files with any text editor. Refresh the browser to see changes.

## Publish free with GitHub Pages

1. Create or sign in to a GitHub account at https://github.com/.
2. Create a **public** repository named exactly `YOUR-GITHUB-USERNAME.github.io`, replacing the placeholder with your GitHub username. Do not include `https://`.
3. Upload the contents of this folder to the repository's root. Make sure `index.html` is directly in the root, not inside another folder.
4. In the repository, open **Settings → Pages**.
5. Under **Build and deployment**, choose **Deploy from a branch**.
6. Select branch `main` and folder `/(root)`, then click **Save**.
7. Wait for the Pages deployment to finish. Visit `https://YOUR-GITHUB-USERNAME.github.io/`.

GitHub Pages may take several minutes to publish after the first setup or a change. Use the repository's **Actions** tab to inspect deployment status if needed.

Official instructions: https://docs.github.com/en/pages/quickstart

## Cost

This static site can be hosted on GitHub Pages for $0 using the free `github.io` address. A custom domain is optional and generally costs money. GitHub Pages publishes the website publicly, so never commit passwords, private documents, private contact information, or anything you do not want public.

## Limitations

This is a static website. It does not include a backend, database, private login, or working contact form. The email button opens the visitor's email app. Avoid putting secrets or private data in the source files.
