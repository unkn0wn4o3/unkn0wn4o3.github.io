# ᴜɴᴋɴᴏᴡɴ_𝟺ᴏ𝟹 — Personal Archive

A responsive, dark multi-colour personal website based on the reference video.

## Contents
- `index.html` — profile, games, hobbies, anime, movies, series, animated films, breakfast, and social links
- `styles.css` — responsive layout and dark colour palettes
- `script.js` — mobile navigation and live media thumbnails
- `assets/crown-icon.png` — supplied website icon
- `assets/profile-picture.jpg` — supplied profile picture

## Real images
Media cards request thumbnail images from Wikipedia's public article image API when a visitor is online. These are real article thumbnails, not AI-generated art. If an image is unavailable, the card keeps its designed background and title. Food images use Wikimedia's Special:FilePath redirects.

## Publish
1. Extract this ZIP.
2. Upload the contents into the root of `https://github.com/unkn0wn4o3/unkn0wn4o3.github.io` (including the `assets` folder). Do not upload the ZIP itself.
3. Replace existing files when prompted and commit the changes.
4. Open the site and press Ctrl+F5.
